## 1. 项目特点

### 🎯 核心定位

把"思维导图"作为思考的容器，把"AI"作为思考的协作者，把"本地文件"作为思考的仓库。**所有内容都在你的电脑本地，不依赖云端服务也能完成全部核心功能**。

### ✨ 十二大亮点

| # | 亮点 | 说明 |
|---|------|------|
| 1 | **四视图实时联动** | 思维导图 / 大纲 / 关联图 / Markdown 双向同步，表格/代码块/图片/引用原子块尽量保留 |
| 2 | **AI 智能体深度集成** | 100+  个 AI 工具，覆盖生成、整理、扩展、挖空、改写、出题、复习全流程 |
| 3 | **三步挖空流程** | 机器挖 → AI 补 → AI 复查，可选"仅规则兜底"或"AI 介入"；挖空自动应用艾宾浩斯复习 |
| 4 | **AI 背诵改写** | 自动为节点生成【记忆简写】+ 摘要，节点越改越好背 |
| 5 | **本地知识库** | txt/md/json/docx/pptx/xlsx/pdf/图片 OCR 全部支持，BM25 + 向量混合检索 |
| 6 | **多分屏 + 拖拽标签** | Obsidian 式分屏树，标签可拖到边缘组合多个导图 |
| 7 | **后台 AI 干活** | AI 按"指定文件路径"在后台修改文件，不抢占前台编辑，完成后通知 |
| 8 | **三方集成** | 飞书文档/云盘/机器人、微信推送、定时任务、外部 MCP、自定义工具 |
| 9 | **云盘自动备份** | rclone WebDAV 镜像同步，保存即自动上传到坚果云/123 云盘/自建网盘 |
| 10 | **艾宾浩斯复习** | 1/3/7/15/31 天复习曲线，支持 desktop_todo_Calendar 双向同步 |
| 11 | **完全本地优先** | 默认存储在 `C:\我的mindmap`，所有工具可离线使用，AI 配置可选 |
| 12 | **开放扩展** | Skills 知识、MCP 服务端协议、自定义工具子进程沙箱，三层扩展能力 |

### 🎁 适合谁

- 🧠 **学生/考研**：背书、做笔记、艾宾浩斯复习计划
- 📚 **知识工作者**：读书笔记、读书会、内容创作结构化
- 💻 **程序员**：技术学习笔记、API 速查、文档脑图
- ✍️ **写作者**：大纲生成、章节扩展
- 🧑‍🏫 **老师**：教案组织、知识点挖空给学生做练习

## 3. AI 功能完整列表

### 3.1 右键节点触发的 AI 功能

| # | 功能 | 用途 | 是否带 AI 标签 |
|---|------|------|-----------------|
| 1 | **AI 续写此节点** | 让 AI 根据当前节点内容自动续写其子节点 | ✅ |
| 2 | **AI 新增子节点** | 让 AI 自动补充该节点缺失的子节点 | ✅ |
| 3 | **AI 背诵改写** | 把长文本改写成【记忆简写】+ 摘要（自动应用谐音） | ✅ |
| 4 | **AI 智能挖空** | 让 AI 在选中节点自动挖空关键词（前提：可仅规则挖空） | ✅ |
| 5 | **AI 出题** | 让 AI 在选中节点下生成单选/多选/填空/简答题 | ✅ |
| 6 | **将节点添加到 AI 对话** | 把选中节点的文本贴到 AI 对话输入框 | ✅ |

### 3.2 右键画布（空白处）触发的 AI 功能

| # | 功能 | 用途 | 是否带 AI 标签 |
|---|------|------|-----------------|
| 1 | **一键整理导图** | 让 AI 重新组织结构，原文保留，结果写到新 .smm | ✅ |
| 2 | **AI 全文挖空** | 对整张图所有节点自动挖空关键词 | ✅ |

### 3.3 AI 对话面板内置的 AI 功能（双击节点触发或工具调用）

| # | 功能 | 说明 |
|---|------|------|
| 1 | **AI 生成思维导图** | 输入主题，AI 自动生成完整的多层级导图 |
| 2 | **AI 转换文档** | 把 PDF/Word/Excel/PPT/图片转成思维导图 |
| 3 | **AI 文档问答** | 在知识库中跨文件查找答案 |
| 4 | **AI 语义搜索** | 基于向量的语义检索（比关键词更智能） |
| 5 | **AI 联网搜索** | 实时联网获取最新信息 |
| 6 | **AI 阅读网页** | 抓取网页正文 |
| 7 | **AI 复习检查** | 检查今日复习计划完成情况 |
| 8 | **AI 沉淀 Skill** | 把成功的工作流沉淀为可复用的 Skill |
| 9 | **AI 创建技能** | 通过自然语言生成新的 Skill 脚本 |

### 3.4 挖空功能详细说明

挖空是本项目最独特的功能，分三层流程：

```
用户操作（右键 → AI 智能挖空）
    ↓
步骤 1：机器用规则/正则提取考点（保守策略）
    ↓
步骤 2：AI 在机器未覆盖的节点上补充挖空
    ↓
步骤 3：AI 快速复查质量，补提示或删除不合理挖空
    ↓
结果：节点加 cloze 标记，答案隐藏，点击显示
```

**用户可选择仅"机器挖空"模式**，不走 AI，速度快且不消耗 AI 调用次数。

### 3.5 复习计划自动绑定

挖空的节点会自动进入艾宾浩斯复习计划：
- 1 天后复习
- 3 天后复习
- 7 天后复习
- 15 天后复习
- 31 天后复习

完成状态可与 desktop_todo_Calendar 桌面日历双向同步。

## 5. 技术架构

### 5.1 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron 28 |
| 前端 | Vue 3 + Vite 5 + Element Plus |
| 思维导图引擎 | simple-mind-map |
| 后端 | Node.js（主进程） |
| 数据存储 | 本地文件（.smm / .md） + SQLite（知识库） + 向量索引 |
| AI 接口 | OpenAI 兼容协议（GPT/Claude/DeepSeek/通义/Kimi/本地 Ollama 等） |
| 知识库检索 | BM25（中文）+ Embedding Worker（向量） |
| 扩展协议 | MCP（Model Context Protocol）+ 自定义工具子进程 + Skills |

### 5.2 模块划分

```
electron/                主进程
  ├── ipc/              IPC 模块（AI、文件、数据库、MCP、安全等）
  ├── utils/            主进程工具（store、secureStore）
  ├── main.js           主进程入口
  └── preload.js        渲染进程桥接

src/                    渲染进程
  ├── components/       Vue 组件
  ├── stores/           Pinia 状态
  ├── services/         业务服务（AI、知识库、搜索等）
  ├── utils/            工具（挖空、记忆、复习计划等）
  ├── prompts/          AI 提示词
  └── App.vue           入口

custom-tools/           用户自定义工具示例
skills/                 Skills 示例
docs/                   项目文档 + GitHub Pages Demo
```

### 5.3 安全设计

- 文件路径白名单（fsGuard）
- Shell 命令独立 cwd 校验
- 自定义工具子进程沙箱化（隔离 RCE 风险）
- 环境变量白名单（21 个 key，杜绝 NODE_OPTIONS 劫持）
- HTTP 服务 Token 鉴权 + 60 天有效期
- 向量数据强校验，防注入

## 6. 运行环境

- **操作系统**：Windows 10+（主要目标平台）
- **运行时**：Node.js 18+（开发需要；普通用户安装包自带）

- **可选依赖**：
  - rclone（云盘同步功能）
  - desktop_todo_Calendar（复习计划同步）

## 7. 快速开始

### 7.1 普通用户（仅使用）

```bash
# 1. 下载最新安装包
# 访问 https://github.com/bubu-LZY/my-mindmap-agent/releases/latest
# 下载 my-mindmap agent Setup <version>.exe

# 2. 双击安装

# 3. 打开后到「设置 → AI 配置」填入你的 API Key

# 4. 开始使用
```

### 7.2 开发者

```bash
# 克隆仓库
git clone https://github.com/bubu-LZY/my-mindmap-agent.git
cd my-mindmap-agent

# 安装依赖
npm install

# 启动前端开发服务器（仅 Vite）
npm run dev

# 启动 Electron + Vite 完整开发模式
npm run electron:dev

# 构建生产版本（生成安装包）
npm run electron:build
```
