# 推广亮点合集（按推荐力度排序）

> 仅基于当前 `my-mindmap-agent v4.8.3` 实际代码梳理，未做夸大。
> 排序原则：用户能直接感知 / 一眼看懂 / 在通用痛点上能秒杀同类 → 强度递减。

***

## Tier 1｜一眼看懂、一眼爱懂的「杀手锏」

### 1. 一键 AI 全文挖空——复习党的「背单词神器」级功能

**为什么耀眼**：

- 三步流程「机器挖空 → AI 补挖 → AI 快速过一遍」，任何节点文字都能出题。

- 并行多 Agent：节点多时自动拆成 N 路子 Agent 同时挖，结果聚合。

- 三档策略（保守 / 激进 / 全图）兜底，AI 失败自动降级。

- 隐藏答案、点击显示，Word/Excel 的"查找框"式体验。
  **推荐话术**：「把你复习的资料丢给它，全文自动挖空，重点自测，比 Anki 还省事。」

### 2. 后台 AI 干活——真正"不打扰"的智能体

**为什么耀眼**：

- 用户下达"读 3 个 PDF + 生成导图"后，AI 在后台独立实例中跑，不抢当前正在编辑的文件。

- LRU 缓存后台实例，避免反复重建。

- 多文档 `convert_doc_to_mindmap(file_paths=[])` 一次传入，整合作图全程后台。

- 任务结束只回写"结果文件路径"，用户随时点开。
  **推荐话术**：「任务交给它，你该干嘛干嘛。完了告诉你哪个文件已经整理好。」

### 3. 飞书 / 微信一键打通——导图不是孤岛

**为什么耀眼**：

- 思维导图 → 飞书在线文档（节点层级变 Heading）。

- 飞书云盘 / 群消息 / 微信个人 / 群聊推送（文本、图片、文件全覆盖）。

- 定时任务调度器 + 飞书机器人，定时把整理好的导图推送给团队。
  **推荐话术**：「导图画完直接推到飞书/微信，不需要截图，不需要复制粘贴。」

## Tier 2｜会让人惊呼"真全"的「能力广度」

### 4. 100+ 个 AI 工具——一个 Agent 抵一套办公套件

**为什么耀眼**：

- 工具分类 12 个：Mindmap / Node Ops / Edit / View / Export / Feishu / Push / File / AI / Study / KB / Web / Custom / MCP / Skills。

- 节点操作细到：uid/关键词/层级模式（叶子/父叶子/all）批量定位 → 一次调用处理整片节点。

- 全文搜索替换、格式化刷、合并/拆分节点、外框、关联线……几乎覆盖所有 PowerPoint/Word 形态的操作。
  **推荐话术**：「你要的操作，AI 全都会。不用手点。」

### 5. 三套并行记忆——AI 真的越来越懂你

**为什么耀眼**：

- 永久记忆（永久规则）+ AI 长期记忆（AI 自动提取）+ 任务内对话上下文，分层管理。

- 设置面板可视化编辑，永久记忆可手动调整。

- 记忆保存有防误记（任务动词和长期意图词区分）。
  **推荐话术**：「用得越久，它越懂你的偏好。」

### 6. 知识库语义搜索——BM25 + 向量混合检索

**为什么耀眼**：

- 索引范围：txt / md / json / docx / pptx / xlsx / pdf / 图片 OCR。

- BM25（中文关键字）+ Embedding Worker（语义）双通道混合打分。

- 跨文件节点、文档切片都能搜；搜索结果可点击跳回具体节点。
  **推荐话术**：「你几年前的笔记，问一句就能找到。」

## Tier 3｜让人感叹"真细"的「体验打磨」

### 7. 四视图联动：思维导图 / 大纲 / 关联图 / Markdown

**为什么耀眼**：

- 一份数据四种呈现，随手切换。

- 表格、代码块、图片、引用块原子结构尽量保留。

- 三视图 HTML 一键导出（导图+大纲+关联图合并到一个交互式页面）。

### 8. 多分屏 + 拖出独立标签页——Obsidian 式工作流

**为什么耀眼**：

- 标签栏鼠标滚轮横向滚动（标签再多也不怕看不到）。

- 多文件并排对照，标签可拆可合。

- 加号按钮一键新增独立标签组，默认欢迎页。

### 9. 一键整理导图——重命名/重构不丢原文

**为什么耀眼**：

- AI 给整张图重新组织结构，但**所有原节点文本严格保留**。

- 输出到新文件，老文件不动。

- 干运行预览（dry-run）+ 安全修复模式。

### 10. 文件内"查找替换"——类 Word/Excel 的查找体验

**为什么耀眼**：

- 所有文本类文件（Markdown/大纲/导图节点）都支持。

- 回车循环下一个、列表点击跳位置、叉号关闭，与 Office 完全一致。

- 当前激活位置自动 scrollIntoView 高亮。

## Tier 4｜开发者友好

### 11. Skills / MCP / Custom Tools 三层扩展

- **Skills**：可复用工作流知识（如 my-mindmap-agent-api）。

- **MCP**：标准 MCP 协议接入外部 Agent 工具。

- **Custom Tools**：用户自建工具（隔离子进程、路径白名单、可调用 PowerShell）。

- **`semantic_tool_search`**：用户描述需求，AI 自动从目录里挑最合适的工具。

### 12. 安全与工程化

- 密码门、secureStore（Windows DPAPI 加密敏感凭证）。

- IPC 通道、HTTP 本地服务双通道能力。

- 自动更新检测（GitHub API + 6 小时周期 + 后台不打扰）。
