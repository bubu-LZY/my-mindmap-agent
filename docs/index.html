思维导图视图 · AI 助手
FEATURE 01

思维导图与 AI 同屏协作

主界面分为三栏：左侧思维导图画布，中间是 AI 助手对话与工具调用结果， 右侧是运行日志（tool call、token 用量、错误都一目了然）。

右侧日志面板会实时显示 AI 的每一步工具调用结果，包括参数、耗时与返回数据， 出错时可直接定位到工具名。

  • 侧边快捷键：快捷键 / 定时任务 一键直达常用面板
  • 上下文锚定：AI 默认围绕"当前打开的 .smm 文件"操作
  • 实时进度：流式 token 输出 + 工具调用动画，所见即所得

复习模式 · 艾宾浩斯曲线
FEATURE 02

复习模式：艾宾浩斯遗忘曲线

复习总览页把"今天该复习哪些节点"按 1 天 / 3 天 / 7 天 / 15 天 / 31 天 五段时间网格排开，勾选完成即自动安排下一轮复习，循环往复直至熟练。

底层依赖 src/utils/reviewPlan.js 实现的间隔算法， 每学完一个就自动写入"待复习队列"，下次启动时 AI 会主动提示你该复习了。

  • 五段间隔勾选完成，进度一目了然
  • "清除所有已完成"一键归档旧记录
  • 与定时任务联动：每日自动汇总到飞书/微信

右键菜单 · AI 工具集
FEATURE 03

右键节点：6 个 AI 工具一键触达

在画布任意节点上点右键，即可调用 AI 完成最常见的 6 类操作—— 续写、新增子节点、背诵改写、智能挖空、出题、把节点送进 AI 对话窗口。

这一套右键菜单直接对应 src/services/toolHandler.js 中的工具调用定义， 每个菜单项都是一次独立的工具调用（rewriteNode / addChildNode / reciteRewrite / smartOcclusion / generateQuiz / sendToChat）， 不用切换窗口、不用复制粘贴。

  • 续写 让 AI 顺着当前节点继续展开
  • 新增 一键加子节点，AI 自动起名
  • 改写 背诵模式专用：AI 用问答口吻重写
  • 挖空 把关键概念换成挖空便于填空背诵
  • 出题 针对该节点自动出考题
  • 对话 把节点内容塞进 AI 对话上下文

大纲视图
FEATURE 04

大纲视图：结构化阅读

当你只想"读"而不是"展开"，大纲模式把同一份数据折叠为可滚动的纯文本大纲， 适合快速浏览、复制和打印。

数据与画布共享：在大纲里编辑节点，回到思维导图视图会自动同步。 这就是为什么同一份"四川川菜"资料能在大纲、思维导图、复习三种视图间无缝切换。

  • 折叠 / 展开节点树，支持快捷键
  • 支持 Markdown 风格的纯文本渲染
  • 可导出为 .md / .txt 用于外部分享

AI 定时任务
FEATURE 05

AI 定时任务：让 AI 主动找你

不是你每次去找 AI，而是让 AI 在你指定的时间自动执行任务。 比如每天早上 8 点自动汇总昨日的复习计划、每周日晚整理本周新增的资料。

任务提示词支持 {{今日日期}} / {{明日日期}} 等动态变量， 模板字段让提示词随上下文自适应。

  • 支持"仅一次 / 每日 / 每周 / 自定义 cron"等多种周期
  • 每个任务独立的执行日志与下次执行时间
  • 与飞书 / 微信推送联动：触发即推送到群里

三方集成 · 飞书 / 微信
FEATURE 06

飞书 / 微信集成：消息秒达

在"三方集成"标签页配置 App Secret 与启用开关，应用启动时自动建连， 定时任务或 AI 触发可自动把生成的导图 / 复习计划推送到指定群。

支持飞书（Lark）与微信（企业微信）双通道，每个群配置独立， 随时"测试连接"验证凭据有效性。

  • 通道开关可独立禁用（如临时停用飞书）
  • 内置"消息内容"编辑器，支持富文本与多群批量
  • API Key / Secret 仅本地存储，不上传云端
设置 — 三方集成
AI 模型配置 · OpenAI 兼容
FEATURE 07

AI 模型配置：兼容 OpenAI completions

默认适配 OpenAI 的 /v1/chat/completions 协议。 你可以使用 OpenAI 官方、Azure、DeepSeek、智谱、火山方舟、任何兼容接口的服务， 也可一键启用自带的硅基流动 / 日日新 等预设。

多套配置并存（"新增/删除"切换），适合不同任务用不同模型—— 比如生成导图用 GPT-4，整理资料用更便宜的轻量模型。

  • 支持 custom 自定义 Base URL 与模型名
  • API Key 加密本地存储，支持"补全"开关（流式输出）
  • "温度"等高级参数可在二级标签页配置
